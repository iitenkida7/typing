# Typing - 楽しく学ぶ英語タイピング練習

小学生向けの英語タイピング練習サービス。タイピングを通じて、英語のスペルと発音を楽しく学習できます。

## 🎯 プロジェクト概要

このサービスは、小学生が「楽しく、幅広く」英語を学べるタイピング練習プラットフォームです。従来の日本語タイピング練習とは異なり、**英語のスペルをタイピング練習しながら、同時に英語表現を学ぶ**ことに特化しています。

## 👥 対象ユーザー

- 小学生（英語学習を始めた児童）
- 楽しく英語を学びたい学習者

## ✨ 主な特徴

### 1. **英語スペルのタイピング練習**
従来の日本語をベースとしたタイピング練習とは異なり、英語の単語やフレーズのスペルをタイピングします。

### 2. **日本語併記で理解を深化**
英語のスペルだけでは学習効果が限定的なため、日本語の意味を併記。英語と日本語を同時に学べます。

### 3. **画像による視覚的学習**
単語の意味をより深く理解するため、各問題に関連する画像を表示。ビジュアルを通じて自然な英語理解を促進します。

### 4. **発音音声の提供**
正しい英語発音を学べるよう、各問題の音声を再生可能。耳からの学習で、より自然な英語習得をサポート。
